# Demand Sensing Agent Mock Data

Synthetic SMME retail dataset for D1-D5 Demand Sensing.
- 6 products
- 180 days of limited history
- Weekly and payday patterns
- Local events and promotions
- Three deliberately dirty transaction records for D1 testing
- No real customer data

Files: products.csv, transactions.csv, promotions.csv, local_events.csv, calendar.csv

Dirty records:
BAD-001 = negative quantity
BAD-002 = missing quantity
BAD-003 = extreme outlier
